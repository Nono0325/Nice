# 雙軸龍門機械手臂智能控制系統 - 電氣配線與硬體連接手冊

本手冊詳細說明 **樹梅派 4 (Raspberry Pi 4)**、**2HSS86H 閉環驅動器**、**57BYG-112 閉環步進馬達**、**QN-1805-E1 方形接近開關**、**LSD-P25/20 直流電磁鐵** 與 **817/PC817 光耦隔離板** 之間的完整電氣配線架構。

---

## 1. 系統電源分配架構

為杜絕工業強電干擾並確保樹梅派穩定運作，系統採用 **三組獨立或隔離電源**：

1. **馬達驅動電源 (DC 36V ~ 48V / 10A ~ 15A)**：專供兩台 2HSS86H 驅動器與 3 顆 57BYG-112 馬達。
2. **感測器與電磁鐵電源 (DC 12V 或 24V / 5A)**：專供 13 顆 QN-1805-E1 接近開關及 4 組 LSD-P25/20 電磁鐵。
3. **樹梅派邏輯電源 (DC 5V / 3A USB-C)**：專供樹梅派 4 主機。

> [!IMPORTANT]
> **共地原則 (Common Ground)**：
> 透過 817 光耦隔離板後，高壓側（24V/12V）與樹梅派 3.3V 邏輯側由光電徹底物理隔離，**樹梅派 GND 與 24V GND 請勿直接直通**，以維持最優異的抗干擾防護！

## 3. 2HSS86H 閉環驅動器與馬達配線

### (1) 驅動器控制訊號接線 (共陰極接法 - Recommended for Pi 3.3V)
2HSS86H 支援 3.3V ~ 5V 信號電平：
* **PUL+** -> 接樹梅派 GPIO 脈衝引腳 (X: GPIO 18, Z: GPIO 12)
* **PUL-** -> 接樹梅派 GND
* **DIR+** -> 接樹梅派 GPIO 方向引腳 (X: GPIO 23, Z: GPIO 8)
* **DIR-** -> 接樹梅派 GND
* **ENA+** -> 接樹梅派 GPIO 致能引腳 (X: GPIO 24, Z: GPIO 7)
* **ENA-** -> 接樹梅派 GND
* **ALM+** -> 經 817 光耦板或直接接樹梅派警報 GPIO (X: GPIO 21, Z: GPIO 25)
* **ALM-** -> 接樹梅派 GND

> [!NOTE]
> **馬達致能鎖定說明 (ENA)**：
> 2HSS86H 內部為光耦輸入。當 ENA 輸入無電壓差時（ENA+ 與 ENA- 斷開），驅動器處於 **鎖定致能狀態（馬達具有保持力矩）**；當 ENA+ 輸入高電平導通時，驅動器關閉輸出（馬達處於自由釋放狀態，可用手旋轉推動）。

### (2) 57BYG-112 馬達動力與編碼器配線
* **動力線 (4線兩相)**：
  * A+ / A-：相 A 線圈組 (例如 黑 / 綠)
  * B+ / B-：相 B 線圈組 (例如 紅 / 藍)
* **閉環編碼器線 (6芯插頭)**：
  * VCC -> 驅動器 +5V 輸出
  * GND -> 驅動器 EGND
  * EA+ / EA- -> 驅動器 A 相編碼器差分輸入
  * EB+ / EB- -> 驅動器 B 相編碼器差分輸入

### (3) Z 軸雙 57BYG-112 馬達同步驅動配線方式
* **並聯接法 (推薦)**：將 Z 軸兩顆 57BYG-112 的對應相線 (A+ 與 A+、A- 與 A-、B+ 與 B+、B- 與 B-) 並聯接入驅動器。
* **反向同步處理**：若兩顆馬達安裝為對稱鏡像結構（旋轉方向相反時滑台同向升降），只需將其中一顆馬達的 A+ 與 A- 兩線對調即可實現反向同步運轉！
* **主編碼器連接**：將主承重側馬達的編碼器回授線接入 2HSS86H 驅動器進行閉環控制。

## 4. QN-1805-E1 方形電感接近開關 (13 顆) 接線

* **QN-1805-E1 標準線色 (NPN 常開 NO 型)**：
  * **棕色線 (Brown)**：接感測器直流電源正極 (+24V DC 或 +12V DC)
  * **藍色線 (Blue)**：接感測器直流電源負極 (0V / 24V GND)
  * **黑色線 (Black)**：信號輸出端 (感應到金屬時導通接地)

### 經 817 光耦隔離板接法：
1. **輸入側 (24V 端)**：
   * 817 光耦板 IN+ 接 +24V
   * 817 光耦板 IN- 接接近開關黑色信號線 (當感應到金屬時，開關內部接地，光耦內部 LED 發光)
2. **輸出側 (樹梅派 3.3V 端)**：
   * 817 光耦板 VCC 接樹梅派 Pin 1 (3.3V)
   * 817 光耦板 GND 接樹梅派 GND
   * 817 光耦板 OUT 接樹梅派對應輸入 GPIO (例如 GPIO 17, 27, 22, 10, 9, 11...)
   * *感應到金屬時，樹梅派對應引腳讀取到 LOW (0)*。

## 5. LSD-P25/20 強力直流電磁鐵 (4 組) 與 PC817 驅動

* **控制流程**：
  樹梅派 GPIO (3.3V) -> PC817 光耦轉接模組 / 功率 MOS 模組 -> 12V/24V 電源切換 -> LSD-P25/20 電磁鐵。
* **必備保護元件 (續流二極體)**：
  電磁鐵為大電感負載，在斷電瞬間會產生高達數百伏特的感應反電動勢 (Flyback Voltage)。
  **必須在每顆 LSD-P25/20 電磁鐵的兩端反向並聯一顆續流二極體 (如 1N4007 或 FR107)**：
  * 二極體陰極（有白色標線端）接電磁鐵正極 (+12V/24V)
  * 二極體陽極接電磁鐵負極 (MOS/繼電器開關端)

## 6. 上電與調校標準程序

1. **第一階段：空載與邏輯驗證**
   * 不接馬達高壓電源，僅啟動樹梅派與感測器 24V。
   * 開啟網頁控制台 `http://<樹梅派IP>:8000`。
   * 用金屬片依序靠近 13 顆接近開關，觀察網頁上對應燈號是否點亮（確認 X左中右、Z上下、手臂8點無接錯）。
2. **第二階段：馬達致能與點動方向校正**
   * 接上 36V 馬達電源。
   * 點擊網頁上「馬達致能鎖定」，測試手推滑台是否鎖死；點擊「離合釋放」，測試是否可手動推動。
   * 選擇「單步 1.0mm」，點擊 X+ 與 Z+，確認滑台移動方向符合預期（若反向，於網頁「馬達設定」勾選「方向信號反轉」並儲存）。
3. **第三階段：全自動歸零程序驗證**
   * 手將 Z 軸移至中間，點擊「全軸智慧歸零」。
   * 系統會先將 Z 軸升起觸碰 Z_UP，退回精碰後設為原點；接著 X 軸向左觸碰 X_LEFT，退回精碰完成全自動歸零！
